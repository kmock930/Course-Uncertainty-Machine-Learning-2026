# Timesheet Webapp
## Problem
I have different career opportunities throughout my life. Each of which requires some administrative work to trace my working hours as a formal documentation with my supervisor/lead; or to trace my ongoing job applications when I am seeking for new ones. However, logging manually on an Excel seems too time-consuming. 
## User Story
1. As a user, I'd like to log in to my dashboard securely, via common authentication methods like Google, GitHub, MS account, and etc. 
2. As a designer, I'd like to have a visibly clear, simple in design (i.e., in light color tone), and any existing React free templates which provides convenience for developers to directly incorporate well-developed Material-UI components and provide user-friendly functions. 
3. As a user, I'd like to have my dashboard as a viewable region on the main portion (66%) on my landing page, followed by a collapsable side bar on the left (of 33% screen).
4. As a user, on my landing page, I'd like to view my current job, working location (i.e., City + Country), working mode (e.g., On-site / Hybrid), salary + paycheque frequency (weekly / biweekly / monthly) with proper currency indicator, annual salary with proper currency indicator, and ongoing job applications (that are not yet rejected or offered) with their statuses.
5. As a user, I'd like to have a separate linkable page (from the sidebar menu) that allows me to enter my working hours per week, so that I could save my progress and submit it after a working week. 
6. As a user, I'd like to have a config page (clickable from an icon on the right corner) that sets my employer's name and contact email, my annual salary + currency, working region and working mode.
7. As a user, I'd like to have a page from the sidebar that allows me to contact my supervisor at work if I have any administrative issues like reporting my OT.
